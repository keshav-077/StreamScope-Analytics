# StreamScope Analytics Dashboard

Built with **React 19 + TypeScript + Vite + Tailwind CSS v4**

This is the analytics dashboard for StreamScope Analytics, providing real-time spatial intelligence visualization, multi-object tracking, and forensic investigation tools.

## Features

- 🎥 Live video streaming with synchronized SVG vector overlays
- 📊 Real-time event monitoring and spatial analytics
- 🔍 Sub-second forensic video navigation
- 🎯 Object trajectory path visualization
- 🤖 AI-powered investigation agent integration
- 🌊 Spatial intelligence with metric homography

## Development

```bash
npm install
npm run dev
```

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide React Icons
- Base UI Components
